# 📊 PhonePe Transactions Analysis Dashboard (Power BI)

## 📘 Project Overview
This project presents a comprehensive Power BI Dashboard analyzing **PhonePe transactions**, covering multiple financial services such as **Money Transfers, Loans, Insurance, and Bill Payments**.  
The dashboard provides insights into user activity, transaction success rates, payment failures, and monthly trends.  

The goal of this project is to visualize business KPIs and identify patterns to improve transaction efficiency and user satisfaction.

---

## 🛠️ Tools & Technologies Used
- **Power BI** – Dashboard design and visualization  
- **Power Query** – Data cleaning and transformation  
- **Excel** – Data source and preparation  
- **DAX Functions** – KPI creation and measures  

---

## 📂 Dataset
The dataset includes details about:
- Transaction types (Loans, Insurance, Recharge, Money Transfer)
- Transaction amounts (successful & failed)
- Failure reasons (Server error, Wrong PIN, Insufficient balance)
- Monthly trends and service performance

## 📈 Insights Gained
- Loans and Insurance generate the **highest transaction volume**.
- Most failures occur due to **server errors and wrong PIN entries**.
- Peak transaction months vary by service type.
- Power BI’s slicers and visuals make the analysis interactive and insightful.

## 🚀 How to Use
1. Download the `.pbix` file and open it in **Power BI Desktop**.  
2. Connect the dataset (`Phonepe-Final-Dataset.xlsx`) if prompted.  
3. Explore the visuals using slicers and filters for detailed insights.
